# Acre Scouts Website

Static website for Acre Scouts, ready for GitHub Pages or regular hosting.

## Main files

- `index.html`: page structure and business information
- `styles.css`: design and mobile layout
- `script.js`: navigation, inquiry form and content rendering
- `content.js`: easy-to-edit photos, videos and partners
- `logo.jpeg`: Acre Scouts logo

## Add photos or videos

1. Put photos in `assets/photos` or videos in `assets/videos`.
2. Open `content.js`.
3. Copy the relevant example and change its file name and text.

Keep uploaded videos short and compressed. For large videos, YouTube is a
better option.

## Add partners

1. Put the partner logo in `assets/partners`.
2. Open `content.js`.
3. Copy the partner example and update its details.

## Deploy

Upload every file and folder to the hosting root. For GitHub Pages, publish the
`main` branch from the repository root.
